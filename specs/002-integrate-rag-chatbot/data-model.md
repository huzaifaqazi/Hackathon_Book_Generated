# Data Model: Integrated RAG Chatbot

This document defines the data structures used in the RAG chatbot.

## 1. ContentChunk

Represents a segment of text extracted from the book. This will be stored in Qdrant.

-   **chunk_id** (UUID, Primary Key): Unique identifier for the chunk.
-   **content** (TEXT): The actual text content of the chunk.
-   **metadata** (JSONB): Associated metadata.
    -   **source_url** (STRING): The URL of the page where the chunk originated.
    -   **heading** (STRING): The heading of the section containing the chunk.
    -   **page_title** (STRING): The title of the page.
-   **embedding** (VECTOR): The vector embedding of the content.

## 2. ChatSession

Represents a single conversation with a user. This will be stored in Neon Postgres.

-   **session_id** (UUID, Primary Key): Unique identifier for the chat session.
-   **user_id** (STRING): Identifier for the user (can be anonymous).
-   **created_at** (TIMESTAMP): Timestamp of when the session was created.
-   **history** (JSONB): A list of previous messages in the conversation.
    -   `{ "role": "user" | "assistant", "content": "message text" }`

## 3. QueryLog

Logs each query for analysis and improvement. This will be stored in Neon Postgres.

-   **log_id** (UUID, Primary Key): Unique identifier for the log entry.
-   **session_id** (UUID, Foreign Key -> ChatSession): The session in which the query was made.
-   **query** (TEXT): The user's query.
-   **retrieved_chunks** (JSONB): Information about the chunks retrieved from the vector store.
    -   `{ "chunk_id": "...", "score": "..." }`
-   **response** (TEXT): The response generated by the LLM.
-   **timestamp** (TIMESTAMP): Timestamp of the query.

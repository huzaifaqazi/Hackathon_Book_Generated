# Chapter 3.7: Assignment + Mini Project (Humanoid Isaac Navigation)

This assignment is the culminating project for Module 3, designed to integrate your understanding of NVIDIA Isaac Sim, Synthetic Data Generation (SDG), Isaac ROS perception modules (VSLAM), and humanoid navigation using adapted Nav2 concepts. You will set up an environment in Isaac Sim, generate synthetic data, and enable a humanoid robot to navigate autonomously.

## Project Goal

Develop an Isaac Sim project that enables a simulated humanoid robot to autonomously navigate a predefined environment from a starting point to a goal, leveraging Isaac ROS VSLAM for localization and mapping. Your solution should:

1.  Set up a realistic simulation environment in NVIDIA Isaac Sim.
2.  Integrate a humanoid robot model capable of locomotion.
3.  Utilize Isaac ROS VSLAM to provide accurate localization and mapping.
4.  Implement an adapted navigation strategy for the humanoid to reach a goal.
5.  Optionally, demonstrate synthetic data generation for a perception task.

## Deliverables

1.  **Isaac Sim Project**: A complete Isaac Sim project with your environment, humanoid robot, and navigation setup.
2.  **ROS 2 Package(s)**:
    -   A `humanoid_isaac_nav` ROS 2 package containing:
        -   Launch files to bring up Isaac Sim, spawn the humanoid, launch Isaac ROS VSLAM, and configure the Nav2 stack (or your adapted humanoid navigation solution).
        -   Any necessary configuration files (e.g., Nav2 parameters, VSLAM parameters).
    -   (Optional) Python script for synthetic data generation within Isaac Sim.
3.  **Map**: A generated map of the environment used for navigation.
4.  **Report**: A concise report (700-1000 words) documenting:
    -   The Isaac Sim environment setup and humanoid integration.
    -   Details of the Isaac ROS VSLAM configuration and performance.
    -   The humanoid navigation strategy, including any adaptations made to Nav2.
    -   Instructions on how to run your project and demonstrate navigation.
    -   (Optional) Explanation of your synthetic data generation pipeline and its purpose.
    -   Screenshots of your humanoid navigating in Isaac Sim, RViz (showing map/localization), and examples of VSLAM output.
5.  **Video Demonstration (3-5 minutes)**: A video showcasing:
    -   Your humanoid robot spawning and localizing in the Isaac Sim environment.
    -   The humanoid autonomously navigating from a start to a goal position, avoiding obstacles.
    -   Real-time visualization of VSLAM and navigation components (e.g., in RViz or Isaac Sim's debug views).
    -   (Optional) A brief segment demonstrating synthetic data generation.

## Step-by-Step Guide

### Step 1: Isaac Sim Environment Setup

-   **Launch Isaac Sim**: Start Isaac Sim.
-   **Load/Create Environment**: Use a pre-built Isaac Sim environment (e.g., a warehouse, indoor office) or create a simple custom environment using USD assets. Ensure it has some obstacles and features for navigation.
-   **Import Humanoid**: Import your humanoid robot model into the Isaac Sim environment. Ensure its joints are properly configured for control.
-   **Add Sensors**: Configure simulated sensors (e.g., stereo cameras, IMU) on your humanoid within Isaac Sim to publish data to ROS 2 topics. Ensure the topics match what Isaac ROS VSLAM expects.

### Step 2: Isaac ROS VSLAM Integration

-   **Install Isaac ROS VSLAM**: Ensure `isaac_ros_visual_slam` is installed and built in your ROS 2 workspace (refer to Chapter 3.5).
-   **Launch File for VSLAM**: Create a ROS 2 launch file in your `humanoid_isaac_nav` package to:
    -   Launch Isaac Sim as a ROS 2 bridge (if not already running).
    -   Launch the `visual_slam_node` from `isaac_ros_visual_slam`.
    -   Configure the `visual_slam_node` parameters (e.g., `frame_id`, camera intrinsics, IMU topic remapping) to correctly subscribe to your humanoid's sensor data from Isaac Sim.
-   **Map Generation**: Once VSLAM is running, drive your humanoid (teleoperate in Isaac Sim) around the environment to build a map. Save this map for later use with Nav2.

### Step 3: Humanoid Navigation Setup (Adapted Nav2)

-   **Nav2 Installation**: Ensure Nav2 is installed in your ROS 2 workspace.
-   **Load Map**: Use `map_server` to load the map generated by VSLAM.
-   **Configure Nav2**:
    -   Configure `amcl` (or an equivalent localization node) to localize the humanoid within the map, using VSLAM odometry and IMU.
    -   Configure `costmap_2d` layers. Adjust the robot's footprint to be suitable for your humanoid.
    -   **Humanoid-Specific Local Planner**: This is the most challenging part. Replace the default Nav2 controller with:
        -   A simple script that receives velocity commands from Nav2's controller and translates them into basic humanoid movements (e.g., turn-in-place, move-forward gait). This will be a simplification of a full whole-body controller.
        -   Alternatively, if you have access to a humanoid-specific gait generator, integrate that.
    -   Configure global and local planners with appropriate parameters.
-   **Launch File for Navigation**: Create a ROS 2 launch file to bring up all necessary Nav2 nodes with your custom configurations.

### Step 4: Autonomous Navigation Demonstration

-   **Launch Everything**: Start Isaac Sim, then launch your `humanoid_isaac_nav` package's main launch file which should bring up VSLAM and Nav2.
-   **Set Initial Pose**: In RViz, set the initial pose of your humanoid on the map.
-   **Send Goal**: Use RViz's "2D Goal Pose" tool to set a navigation goal for your humanoid within the Isaac Sim environment.
-   **Observe**: Monitor the humanoid's movement in Isaac Sim and its localization/path planning in RViz.

### Step 5: (Optional) Synthetic Data Generation for Perception

-   **SDG Script**: Create a Python script within your Isaac Sim project that uses the `omni.syntheticdata` framework.
-   **Randomization**: Randomize object positions, lighting, textures, or even the humanoid's pose to create diverse training examples.
-   **Capture Data**: Capture RGB, depth, and semantic segmentation data for a simple perception task (e.g., detecting a specific object).
-   **Showcase**: Include a snippet of the generated data in your report or video.

# Diagram Generation Prompt Template

This template is used to generate diagrams (Mermaid or SVG) from textual descriptions.

## Input:
- `diagram_type`: The type of diagram (e.g., flowchart, sequence, class, SVG).
- `description`: A textual description of the diagram to be generated.
- `context`: Any specific styling or content requirements.

## Output:
- Mermaid or SVG formatted diagram content.
